sf_xl_small_geometric

Produces:
- processed/train/sf_xl_small_geometric/index.parquet
- processed/train/sf_xl_small_geometric/stats.json

Source data:
- raw/sf_xl/small

Processing steps:
1. ReadImagesStep
   - Recursively scans the raw dataset directory for image files.
   - Builds one row per image with:
     image_id, image_path, filename, utm_east, utm_north,
     utm_zone_number, utm_zone_letter, latitude, longitude,
     pano_id, heading, timestamp.
   - If raw/sf_xl/small/metadata.csv exists, it is left-joined onto the image rows.

2. AssignPlaceIdsStep(cell_size_meters=25.0)
   - Uses the UTM easting/northing of each image.
   - Converts each point to a 25 m grid cell with floor(easting / 25), floor(northing / 25).
   - Assigns place_id = "{zone_number}_{zone_letter}_{cell_x}_{cell_y}".
   - Images in the same 25 m cell become the same training place.

3. RemoveSmallPlacesStep(min_images_per_place=4)
   - Counts images per place_id.
   - Removes any place that has fewer than 4 images.

4. AssignSuperGroupsStep(cell_size_meters=25.0)
   - Reuses the same 25 m grid.
   - Assigns a repeating 2 x 2 supergroup pattern because adjacency_cells defaults to 1.
   - This gives supergroup_id values 0..3.
   - Distinct places inside the same supergroup are guaranteed to be non-adjacent grid cells.

5. SaveFileStep
   - Saves the final dataframe to index.parquet.

6. DatasetSummaryStep
   - Computes summary stats including:
     total_images, num_places, num_supergroups,
     images_per_place stats, images_per_supergroup stats,
     places_per_supergroup stats.

7. SaveFileStep
   - Saves the summary dictionary to stats.json.
